خوانشگر پیامک بانکی - نسخه آزمایشی

این ZIP پروژه منبع Android است، نه APK آماده نصب.
برای ساخت APK فقط با گوشی می‌توانی از GitHub Actions استفاده کنی:

۱) وارد github.com شو و یک حساب بساز یا وارد حساب خودت شو.
۲) یک مخزن جدید (New repository) بساز.
۳) فایل ZIP را از حالت فشرده خارج کن و همه فایل‌ها و پوشه‌های داخلش، از جمله پوشه مخفی .github، را در مخزن بارگذاری کن.
۴) در مخزن، وارد تب Actions شو.
۵) گردش‌کار Build Android APK را انتخاب کن و دکمه Run workflow را بزن.
۶) پس از پایان موفق، از همان اجرای workflow بخش Artifacts فایل BankSmsReader-debug-apk را دانلود کن.
۷) ZIP مربوط به Artifact را باز کن و app-debug.apk را نصب کن. ممکن است اندروید اجازه نصب از منبع ناشناس بخواهد.

محدودیت‌ها و حریم خصوصی:
- این نمونه فقط پیامک‌های جدید بعد از نصب را دریافت می‌کند.
- پیامک‌های قدیمی را وارد نمی‌کند.
- الگوهای تشخیص تراکنش ساده‌اند و همه بانک‌ها را پوشش نمی‌دهند؛ برای هر بانک باید نمونه پیامک واقعیِ بدون اطلاعات حساس بررسی شود.
- برنامه فقط پیامک‌هایی را می‌بیند که روی همین گوشی دریافت می‌شوند.
- داده‌ها در حافظه محلی برنامه ذخیره می‌شوند و به سرور ارسال نمی‌شوند.
- فقط روی گوشی خودت و با رضایت صاحب سیم‌کارت استفاده کن.
- رمز پویا و OTP را وارد یا برای کسی ارسال نکن.
- انتشار در Google Play برای مجوز SMS محدودیت‌های جداگانه دارد؛ این پروژه برای تست شخصی است.
